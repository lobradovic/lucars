# LUCARS Rent-a-Car

This is a web application designed for managing a car rental business. It provides a comprehensive system for tracking and managing vehicles, clients, and rental agreements. The application enables users to register and update information about available cars, maintain a database of clients, and record rental transactions with start and end dates. The goal is to streamline the rental process, reduce paperwork, and improve the overall efficiency of rental operations.

## Tech Stack
`ASP.NET Core` with `MongoDB`
